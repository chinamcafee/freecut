## 概述

本文档记录 FreeCut → HyperFrames 转换器的当前限制和已知问题。

---

## 功能限制

### 1. WebGPU 特效

**限制**：FreeCut 的 WebGPU 自定义特效无法完全映射到 CSS。

**影响**：
- 自定义 shader 特效会被忽略
- 复杂的粒子效果无法转换
- 高级模糊效果可能降级

**缓解方案**：
- 记录不支持的特效到 `unsupportedFeatures`
- 后续通过 WebGL/Canvas 实现自定义渲染

**优先级**：中等

---

### 2. 关键帧精度

**限制**：贝塞尔曲线转换可能有精度损失。

**影响**：
- 复杂的缓动曲线可能不完全一致
- 动画流畅度可能略有差异

**缓解方案**：
- 增加关键帧采样点
- 使用 GSAP 的高精度模式

**优先级**：低

---

### 3. 音频处理

**限制**：高级音频处理（EQ、压缩器）不支持。

**影响**：
- 音频 EQ 设置会被忽略
- 音频效果器无法转换
- 仅支持基础的 volume 和淡入淡出

**缓解方案**：
- 使用 Web Audio API（计划中）
- 预处理音频文件

**优先级**：中等

---

### 4. 混合模式

**限制**：部分混合模式不支持或效果不同。

**影响**：
- 高级混合模式可能降级为 normal
- 某些混合效果在浏览器间不一致

**支持的混合模式**：
- ✅ normal
- ✅ multiply
- ✅ screen
- ✅ overlay
- ⚠️ color-dodge（部分支持）
- ❌ linear-dodge（不支持）

**缓解方案**：
- 记录到 warnings
- 使用最接近的替代模式

**优先级**：低

---

## 性能问题

### 1. 大型项目转换

**问题**：包含大量元素的项目转换耗时较长。

**影响范围**：
- 50+ 元素：2-5秒
- 100+ 元素：5-10秒
- 200+ 元素：>10秒

**优化方案**：
- 实现增量转换
- 添加转换缓存
- 使用 Web Worker

**状态**：计划中

---

### 2. 内存使用

**问题**：大量关键帧数据会占用较多内存。

**影响**：
- 长时间动画可能导致内存压力
- 浏览器可能出现卡顿

**优化方案**：
- 关键帧数据压缩
- 按需加载动画数据

**状态**：待实现

---

## 已知问题

### Issue #1: Shape 元素转换未实现

**描述**：Shape 元素（矩形、圆形、多边形）转换暂未实现。

**影响**：Shape 元素会被跳过，记录到 warnings。

**解决方案**：计划在 Week 04 实现 SVG 生成逻辑。

**优先级**：高

---

### Issue #2: 3D Transform 不支持

**描述**：FreeCut 的 3D 变换（rotateX, rotateY, perspective）不支持。

**影响**：3D 效果会降级为 2D。

**解决方案**：后续添加 CSS 3D transform 支持。

**优先级**：中等

---

### Issue #3: 视频编解码器兼容性

**描述**：某些视频编解码器在浏览器中不支持。

**影响**：
- H.265/HEVC 在部分浏览器不支持
- VP9 在旧浏览器不支持

**解决方案**：
- 添加编解码器检测
- 提供转码建议

**优先级**：高

|-------|---------|-------|
| Chrome | >= 90 | ✅ 完全支持 |
| Firefox | >= 88 | ✅ 完全支持 |
| Safari | >= 14 | ⚠️ 部分支持 |
| Edge | >= 90 | ✅ 完全支持 |

**Safari 限制**：
- 某些 CSS filter 效果不同
- GSAP 动画性能略低

---

## 数据完整性

### 1. 元数据丢失

**问题**：某些 FreeCut 特有的元数据会丢失。

**影响**：
- 编辑历史不保留
- 自定义标签丢失

**缓解方案**：在 HTML 注释中保留元数据。

---

### 2. 可逆性

**问题**：转换不完全可逆。

**影响**：HyperFrames → FreeCut 反向转换可能不完全一致。

**说明**：这是设计限制，两个系统的能力不完全对等。

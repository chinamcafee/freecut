# Week 15 Test Report

Week 15 starts Phase 4 with full release testing.

- FreeCut core: timeline tools, drag and resize, split and merge, undo and redo.
- Effects and transitions: types, parameters, preview render.
- Keyframes and animation: creation, curve editing, playback, export.
- HyperFrames: composition creation, track editing, Studio editing, live preview,
  save/update, blocks insertion, Skills execution, and safe import.
- AI: 50 dialogue scenarios, intent recognition, action execution, and errors.
- Render and data: FreeCut export, HyperFrames export, mixed export, save/load,
  media import, project export, and migrations.

Every compatibility issue follows record, classify, assign, and verify steps.

- Project load: under 2 seconds.
- Edit response: under 100 ms.
- Preview playback: over 30 fps.
- Peak memory: under 1 GB.

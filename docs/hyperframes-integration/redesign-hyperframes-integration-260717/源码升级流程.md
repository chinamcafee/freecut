# HyperFrames 源码升级流程

1. 更新 `provenance/upstream-manifest.json` 中的来源和迁移策略。
2. 运行 `npm run hyperframes:sync-upstream -- --package <id> --runtime-only --dry-run --json` 审查差异。
3. 使用 `--write` 同步，并检查 `upstream-sync-state.json`。
4. 根据 `import-rewrite-map.json` 更新浏览器源码 import；Producer Node 快照保持本地服务边界。
5. 记录本地 patch note，运行目标包核心测试。
6. 运行 `check:hyperframes-runtime-imports`、`check:hyperframes-producer-boundary`、质量矩阵和生产构建。
7. 安全、隐私、成本、渲染、模型与文档门禁全部通过后才能发布。

不要直接编辑同步快照后跳过 patch note；不要让 Producer Node 文件进入 Vite 浏览器依赖图。

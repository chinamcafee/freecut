# HyperFrames 故障排查

| 问题 | 下一步 |
| --- | --- |
| 模型不可用 | 打开模型与能力中心，检查 profile、密钥、额度和服务健康状态。 |
| 校验失败 | 从诊断跳到 Studio 文件或时间线项，修复 blocking 项后重新校验。 |
| 资产缺失 | 在项目库重连资产，确认路径仍位于项目目录内。 |
| Producer 不可用 | 检查 Chrome、FFmpeg、GPU 和本地服务 runtime。 |
| 渲染失败 | 查看 render job 日志，清理失效缓存后重试。 |
| 透明叠加失败 | 使用启用 alpha 的 WebM、MOV 或 PNG 序列。 |
| 费用超限 | 检查估算与预算，选择低成本模型或显式提高限额。 |

支持信息和审计日志会隐藏密钥、prompt 与本地绝对路径。

# HyperFrames 开发者迁移说明

## 当前数据路径

- 权威源：`HyperFramesProjectDirectory`，包含 manifest、`index.html`、`compositions/` 和 assets。
- FreeCut 时间线：继续使用 `type: 'composition'`，通过 `sourceKind: 'hyperframes'` 和 `compositionLinks` 引用项目目录。
- 禁止新增独立 HyperFrames 时间线类型，禁止把单一 HTML 字符串作为项目真相。

## 模块边界

- 浏览器能力通过 `src/features/hyperframes-runtime/adapters` 和 `bridges` 使用。
- Studio、Player、core、parser 和 lint 是源码快照，不以 `@hyperframes/*` npm 包作为产品主路径。
- Producer 是 Node-only 本地服务快照，浏览器只能通过 `HyperFramesRenderService` transport 调用。
- 任何导入、模型写入和渲染都必须经过确认、诊断、审计和可回滚边界。

## 转换原则

- FreeCut 导出生成完整项目目录。
- HyperFrames 导入先保留 source-linked composition，再按需创建原生近似项。
- 近似转换必须返回 loss records，不能替换或删除权威项目目录。

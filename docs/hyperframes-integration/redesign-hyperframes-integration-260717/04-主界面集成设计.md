# 主界面集成设计

## 本章目标

本章说明如何把 HyperFrames 的生成、编辑、预览、诊断、渲染和模型能力无缝放入 FreeCut 非线性编辑器主界面。它聚焦界面结构和交互，不重复底层数据模型。

## 主界面布局

整合后的主界面仍采用 FreeCut 原有编辑器布局：

```text
顶部栏：项目、撤销重做、播放控制、导出、模型状态
左侧栏：媒体库、素材、特效、字幕、AI 生成、HyperFrames 项目库
中间：统一预览器
右侧栏：属性、诊断、变量、AI 助手
底部：多轨时间线
浮层：HyperFrames 工作室、生成结果预览、模型配置
```

## 左侧面板

### AI 生成页签

AI 生成页签提供三种入口：

1. 快速生成：片头、字幕包装、产品短片、网站转视频、动态图形、音乐视频、解释视频。
2. 自然语言输入：用户自由描述目标。
3. 模板与技能：按 HyperFrames 技能、模板、块和组件浏览。

每个入口都必须显示：

- 输出类型。
- 推荐时长。
- 推荐画幅。
- 所需模型能力。
- 预计耗时和费用。
- 是否生成透明背景。
- 是否导入为源链接组合。
- 是否同时生成 FreeCut 原生近似项。

### HyperFrames 项目库

项目库列出当前 FreeCut 项目关联的所有 HyperFrames 项目目录：

- 项目名。
- 缩略图。
- 来源。
- 更新时间。
- 被哪些时间线片段引用。
- 最近一次诊断。
- 渲染缓存状态。

可执行动作：

- 插入到当前时间线位置。
- 打开工作室。
- 导出项目目录。
- 复制为新项目。
- 删除未被引用项目。
- 重新校验。
- 重新生成缩略图。

## 时间线集成

### 片段视觉

HyperFrames 源链接组合片段在时间线中仍是组合片段，但需要增加明确标记：

- 左上角显示“动效源”或“超帧源”标识。
- 片段缩略图来自 HyperFrames 缩略图缓存。
- 右下角显示诊断状态：正常、警告、错误、缓存过期、渲染中。
- 如果有渲染缓存，片段边框显示缓存状态。

### 时间线行为

必须支持：

- 移动。
- 修剪入点和出点。
- 复制。
- 分割。
- 静音或禁用。
- 分组。
- 参与吸附。
- 参与导出。
- 作为普通组合片段参与混剪。

注意：修剪时间线项不应直接修改 HyperFrames 源组合的内部时长，而是改变 FreeCut 外层片段的显示范围。只有用户在工作室中修改组合时长，才改变源目录。

### 右键菜单

右键菜单应包括：

- 打开 HyperFrames 工作室。
- 在文件树中显示源项目。
- 重新生成缩略图。
- 重新校验。
- 渲染为透明叠加。
- 渲染为普通视频。
- 转换为 FreeCut 原生组合。
- 导出 HyperFrames 项目目录。
- 查看生成记录。
- 断开源链接并保留渲染结果。

禁用原因必须明确展示，例如“缺少项目清单”“活动组合文件不存在”“渲染运行时未配置”。

## 统一预览器

### 预览策略

统一预览器需要支持三种层级：

1. FreeCut 原生预览：普通视频、音频、图片、文本、形状、转场和特效。
2. HyperFrames iframe 预览：对单个源链接组合进行实时预览。
3. 混合预览：FreeCut 当前帧与 HyperFrames 当前帧合成。

第一版可以在选中 HyperFrames 片段时显示 iframe 预览，混合导出使用渲染缓存。最终版应支持时间线播放时按帧同步 HyperFrames 播放器。

### 时钟同步

当 FreeCut 播放头位于 HyperFrames 片段范围内：

```text
组合内部时间 = (当前项目帧 - 片段起始帧 + 片段源偏移) / 项目帧率
```

播放器需要支持：

- 播放。
- 暂停。
- 跳转。
- 逐帧前进。
- 逐帧后退。
- 静音。
- 就绪状态。
- 错误状态。

帧同步误差门禁：预览帧、生产器帧和最终导出帧最大误差不超过 1 帧。

## 右侧属性面板

选中 HyperFrames 片段时，属性面板分为六组：

### 基础信息

- 片段名称。
- 源项目名。
- 活动组合文件。
- 画布宽高。
- 帧率。
- 源时长。
- 时间线起点和持续时间。

### 变量

读取 HyperFrames 组合声明的变量，生成表单：

- 字符串。
- 数字。
- 布尔。
- 颜色。
- 选项。
- 媒体引用。

变量修改必须先写入预览态，用户保存后再写回项目目录。

### 生成来源

- 提示词。
- 技能或工作流。
- 模型配置。
- 生成时间。
- 输入哈希。
- 输出哈希。
- 任务日志。

### 诊断

- 结构校验问题。
- 安全问题。
- 缺失资产。
- 不支持反向映射特性。
- 渲染风险。
- 文本溢出。
- 预览与导出差异。

### 渲染

- 渲染格式。
- 透明背景。
- 是否使用 HyperFrames 音频。
- 质量档位。
- 缓存状态。
- 重新渲染。
- 清理缓存。

### 动作

- 打开工作室。
- 重新生成。
- 应用自然语言修改。
- 转为原生组合。
- 导出源项目。

## AI 助手面板

AI 助手位于右侧或底部浮层，支持：

- 读取当前项目上下文。
- 读取选中片段和时间范围。
- 区分聊天、时间线动作、工作室文件修改和技能任务。
- 对破坏性操作生成差异预览。
- 要求用户确认。
- 提供回滚入口。

助手不能直接根据模型输出写入项目。所有写入都必须走动作预览和确认。

## 内嵌工作室

双击 HyperFrames 片段打开工作室。工作室应包括：

- 文件树。
- 源码编辑。
- 可视化预览。
- 时间线视图。
- 元素选择。
- 属性面板。
- 变量编辑。
- 诊断列表。
- 保存按钮。
- 返回 FreeCut 按钮。

第一版可以沿用当前轻量 `HyperFramesStudioPanel`，最终版应接入从 `packages/studio/src` 迁移到 FreeCut 源码镜像层后的布局、播放器、时间线、源码编辑器、属性面板和元素选择能力。

## 生成结果预览

技能任务完成后不应直接写入时间线。应先展示生成结果预览：

- 预览画面。
- 项目文件列表。
- 诊断。
- 资产列表。
- 使用模型和费用。
- 可导入项。
- 可选导入策略。

导入策略：

1. 仅导入源链接组合片段。
2. 导入源链接组合片段并生成可编辑近似项。
3. 先渲染为媒体再导入。
4. 丢弃结果。

## 模型状态入口

顶部栏或 AI 面板顶部应显示模型状态：

- 已配置。
- 缺少密钥。
- 达到配额。
- 使用本地模式。
- 离线不可用。
- 当前任务费用。

点击后进入模型与能力中心。

## 无障碍和键盘操作

必须支持：

- 选中 HyperFrames 片段后回车打开工作室。
- 修饰键加快捷键导出源项目。
- 修饰键加快捷键转换为原生组合。
- 任务运行中可用键盘取消。
- 差异预览可用键盘确认或拒绝。
- 诊断列表可跳转到对应文件或时间线片段。

## 失败体验

常见失败必须可恢复：

| 失败 | 用户提示 | 恢复动作 |
| --- | --- | --- |
| 模型不可用 | 当前模型无法响应 | 切换模型、重试、使用本地模式 |
| 任务失败 | 显示失败阶段和日志 | 重试、复制提示词、报告问题 |
| 校验失败 | 显示阻塞诊断 | 打开工作室修复、重新生成 |
| 资产缺失 | 标出缺失路径 | 重新链接、替换素材 |
| 渲染失败 | 显示运行时缺失或命令失败 | 安装依赖、改用远程渲染 |
| 缓存过期 | 显示重新渲染按钮 | 重新渲染、继续使用旧缓存 |

## 开发落地补充：主面板组件拆分

主界面集成应按 FreeCut 面板边界拆成组件，而不是让 HyperFrames Studio 接管整个应用。

### 左侧面板

新增或扩展：

```text
src/features/hyperframes-integration/ui/HyperFramesGenerateTab.tsx
src/features/hyperframes-integration/ui/HyperFramesProjectLibrary.tsx
src/features/hyperframes-integration/ui/HyperFramesSkillCatalog.tsx
src/features/hyperframes-integration/ui/ModelCapabilityPicker.tsx
```

职责：

- `HyperFramesGenerateTab` 展示自然语言输入、模板、技能推荐、生成计划和成本预估。
- `HyperFramesProjectLibrary` 展示已保存的 HyperFrames 项目目录、缩略图、状态、引用次数。
- `HyperFramesSkillCatalog` 从迁移后的 `upstream/skills` 读取技能分类，不直接读取外部 HyperFrames 仓库。
- `ModelCapabilityPicker` 从模型能力中心读取可用模型，显示文本、视觉、语音、代码、工具调用和本地运行能力。

### 中央预览器

新增播放器桥：

```text
bridges/player-bridge/HyperFramesPlayerHost.tsx
bridges/player-bridge/useFreeCutTimelineClock.ts
bridges/player-bridge/createPreviewDocument.ts
bridges/player-bridge/playerDiagnostics.ts
```

实现要求：

1. `HyperFramesPlayerHost` 封装迁移后的 `hyperframes-player` Web Component。
2. `useFreeCutTimelineClock` 从 FreeCut 播放头读取当前帧，转换为 HyperFrames 秒和帧。
3. `createPreviewDocument` 只从项目仓储读取 HTML，注入允许的运行时脚本和沙箱策略。
4. 播放器事件统一转成 FreeCut 事件：`ready`、`timeupdate`、`durationchange`、`error`、`selectionchange`。
5. 预览器失败时显示诊断，不把 iframe 错误吞掉。

### 时间线

时间线只新增表现和动作，不新增独立轨道类型：

- 片段 badge：`HF`、缓存状态、诊断状态、是否有未保存工作室修改。
- 右键菜单：打开工作室、重新渲染缓存、重新链接项目目录、导出项目目录、转为原生项、查看来源。
- 拖拽行为：外层片段移动和修剪只改 FreeCut 时间线项；进入工作室才改 HyperFrames 内部时长。
- 复制行为：默认复制时间线引用；用户选择“复制为独立 HyperFrames 项目”时才复制项目目录。

### 右侧属性面板

右侧属性面板显示片段级信息，不直接替代 Studio 的 DOM 属性面板：

```text
HyperFramesClipInspector
  SourceSection
  VariablesSection
  RenderCacheSection
  DiagnosticsSection
  ModelProvenanceSection
  ActionsSection
```

变量编辑可以直接写入 manifest 或组合变量，但必须创建快照。复杂 DOM 样式、GSAP、图层和 motion path 编辑进入工作室。

### 工作室浮层

工作室浮层使用两层壳：

1. `FreeCutStudioShell`：负责 FreeCut 面板尺寸、关闭确认、保存状态、快捷键冲突、主题适配。
2. `MigratedStudioSurface`：来自 `packages/studio/src` 的迁移组件子集。

第一版推荐先迁移：

- `components/nle/NLELayout.tsx`
- `components/nle/NLEPreview.tsx`
- `components/editor/SourceEditor.tsx`
- `components/editor/FileTree.tsx`
- `components/editor/PropertyPanel.tsx`
- `player/hooks/useTimelinePlayer.ts`
- `utils/sourcePatcher.ts`

第二版再迁移：

- `DomEditOverlay.tsx`
- `LayersPanel.tsx`
- `TimelineToolbar.tsx`
- `StudioRightPanel.tsx`
- `StudioLeftSidebar.tsx`
- `components/renders/*`
- `components/storyboard/*`

### 快捷键冲突

工作室打开时要注册快捷键作用域：

| 快捷键 | FreeCut 主界面 | 工作室打开时 |
| --- | --- | --- |
| 空格 | 播放主时间线 | 播放当前工作室预览，同时同步 FreeCut 播放头 |
| 删除 | 删除时间线项 | 删除选中 DOM 元素前必须确认 |
| Cmd/Ctrl+S | 保存 FreeCut 项目 | 保存工作室文件并标记 FreeCut 项目 dirty |
| Cmd/Ctrl+Z | FreeCut undo | 优先工作室 undo；跨边界操作写入统一 undo journal |

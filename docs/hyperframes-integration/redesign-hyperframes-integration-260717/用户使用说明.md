# HyperFrames 用户使用说明

## 生成与导入

1. 在 FreeCut AI 面板选择 HyperFrames 生成。
2. 检查技能、模型、素材访问、费用、预计时长和导入策略。
3. 先预览项目目录、manifest 和诊断；只有确认后才写入时间线。
4. 默认导入为 source-linked `composition`。可编辑近似项只是辅助层，项目目录始终是权威源。

## 编辑与导出

- 选中 HyperFrames 片段按 Enter 或使用右键菜单打开 Studio。
- Studio 保存修改到项目目录；关闭未保存内容时必须选择保存、丢弃或继续编辑。
- 导出前 FreeCut 会检查安全诊断、Producer、渲染结果和透明叠加。
- 门禁失败不会损坏项目，按诊断中的下一步动作修复后重试。

## 数据与隐私

- 模型调用前会展示素材、目标服务、隐私模式和费用。
- 本地隐私模式不会自动降级到云端。
- 未确认的生成结果不会写入时间线；导入可通过回滚恢复。
